## Description
List models is a script to help manage your EdgeTX setups. It's run from the Sys>Tools menu on your radio.

The script displays a list of all the model (.yml) files in your radio. Each entry is in the following format:
file_name: model_name, [label1, label2...]

## Requirements
Transmitter with colour screen

## Installation
The latest release can be downloaded from:
https://github.com/RC-SOAR/ListModels/releases/latest

Download the script as directed and follow the instructions.
