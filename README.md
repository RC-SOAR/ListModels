## Description
List models is a tool script to help manage your EdgeTX setups. 

The script displays a list of all the model (.yml) files in your transmitter. Each entry is in the following format:
file_name: model_name, [label1, label2...]

## Requirements
Transmitter with colour screen

## Installation
The latest release can be downloaded from:
https://github.com/RC-SOAR/ListModels/releases/latest
Download the script as directed and follow the instructions.
